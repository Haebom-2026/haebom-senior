# haebom-senior

해봄 고령자용 Android 앱입니다.

## 개발 환경

- JDK 21
- Android SDK Platform 35
- 최소 지원 버전 Android 8.0 (API 26)
- Gradle Wrapper 8.11.1

Android Studio에서 저장소 폴더를 열고 Gradle JDK를 21로 설정합니다. 터미널에서는 Android SDK를 `ANDROID_HOME`으로 지정한 뒤 디버그 APK를 빌드할 수 있습니다.

```sh
./gradlew :app:assembleDebug
```

Windows에서는 `gradlew.bat :app:assembleDebug`를 사용합니다. 빌드 결과는 `app/build/outputs/apk/debug/`에 생성됩니다.

## 화면 안내 연습

1. 앱에서 **접근성 설정 열기**를 누르고 **해봄 화면 안내** 서비스를 켭니다.
2. 앱으로 돌아와 **화면 안내 연습**을 엽니다. **다음** 버튼에 빨간 테두리가 표시됩니다.
3. 표시된 버튼을 누르면 테두리가 **연습 끝내기** 버튼으로 이동합니다. 연습을 끝내거나 다른 앱으로 이동하면 테두리가 사라집니다.

## 다른 앱 화면에서 요청하기

**해봄 화면 안내**를 켜면 다른 앱 위에 **말하기·SOS** 단추가 뜹니다. 단추 묶음은 끌어서 옮길 수 있고, 눌러야 할 곳·자막·키보드를 가리면 스스로 비켜 줍니다.

- **말하기**: 지금 보던 화면 그대로 기기 내 한국어 음성 인식(Android 12 이상)으로 듣습니다. 듣는 동안 단추가 **종료**로 바뀌고, 들리는 말은 큰 자막에 실시간으로 나옵니다. 마이크 권한이 없거나 기기 내 인식이 없으면 말하기 창이 열려 글로도 요청할 수 있습니다.
- 바로 할 수 있는 일(유튜브·연락처·그 밖의 앱 안내)은 그 자리에서 시작하고, 확인이 필요한 일(금융 L2, 사기 의심 L3, 도움 요청, 비밀번호, 정부24)은 말하기 창에서 확인 창을 띄웁니다.
- 안내 중에는 단추가 **다시 말하기**가 됩니다. 새로 시키거나, AI 가 물으면(질문을 읽은 뒤 자동으로 듣기) 대답해서 이어 갑니다. 그 아래 **그만**으로 안내를 끝냅니다.
- **SOS**는 저장된 보호자 번호로 문자 앱을 엽니다. 전송은 어르신이 직접 누릅니다.

## 화면 안내 (서버 AI)

서버 주소가 있는 빌드(debug)는 안내 중 화면이 바뀔 때마다 화면 요소(글자·위치, 최대 60개)를 서버 **#16 guide** 로 보내 다음 행동을 받습니다. 서버가 답하지 못하면 앱에 들어 있는 안내 규칙(연락처·유튜브·정부24)으로 계속합니다. release 빌드는 서버 주소가 정해지기 전까지 앱 규칙만 씁니다.

- **빨간 테두리**: 눌러야 할 곳. 위치 문장과 함께 읽어 줍니다.
- **화살표**: 밀어야 할 방향(상하좌우), 홈·뒤로. 밀다가 찾던 글자가 보이면 바로 짚습니다.
- **자동완성 입력 단추**: 입력 칸을 짚으면 바로 아래에 ‘임영웅’ 같은 말한 검색어·추천어 단추가 뜨고, 눌러야만 글자를 넣습니다.
- 목적지에 도착하면(AI 완료, 말한 앱이 열림, 말한 검색어의 결과) "다 됐어요"라고 알려 주고 안내를 마칩니다.
- 보내지 않는 것: 비밀번호·인증 입력란이 있는 화면(그 화면에서는 "직접 해 주세요"만 안내), 입력란에 적힌 글자, 스크린샷.

정부24는 등본 발급 메뉴(발급하기)까지 안내하고, 회원/비회원·본인인증 화면에서는 직접 하시도록 멈춥니다.

## 보호자 연동 (서버 S1)

앱이 켜질 때 서버에 고령자로 등록(#2)하고 FCM 토큰을 등록(#4)합니다. **가족 연결** 화면에서 연결 코드(#11)를 받아 보호자 앱에 넣으면 연결되고, 연결이 바뀌면 FCM `{kind:"link"}` 로 목록(#18)을 다시 받습니다. 은행·정부24 이용 알림은 #6 으로 보냅니다. 보호자 앱과 맞춘 예전 Mock 데이터 규격은 [docs/guardian-mock-contract.md](docs/guardian-mock-contract.md)에 기록으로 남아 있습니다(앱의 Mock 백엔드는 없앴습니다).

## 디버그 뷰어 (debug 빌드 전용)

앱이 접근성으로 읽은 화면 정보(글자·버튼 위치)를 dev 서버로 보내 웹 뷰어에서 실시간으로 봅니다. 전송 코드는 `app/src/debug`에만 있어 release 빌드에는 없습니다.

1. `app/google-services.json`을 놓고 debug 빌드를 설치합니다(익명 로그인 토큰을 씁니다).
2. 앱 하단 **디버그 뷰어 (dev 전용)** → **디버그 뷰어로 화면 보내기**를 켭니다. 기본은 꺼짐입니다.
3. 접근성에서 **해봄 화면 안내**가 켜져 있으면 5초마다 heartbeat, 화면이 바뀌면 300ms 뒤 마지막 화면을 보냅니다.
4. 웹 뷰어에서 기기가 초록 점으로 보이는지 확인합니다(뷰어 주소는 서버 팀에 확인. 앱 화면의 옛 주소는 바뀔 예정). 마지막 전송 결과는 앱 화면에 표시됩니다.

보내지 않는 것: 비밀번호·인증 입력란이 있는 화면, 금융 앱 화면, 입력란에 적힌 글자, 스크린샷. 노드는 최대 60개, 글자는 100자까지 보냅니다. 실패해도 재시도하지 않습니다.

## Firebase 시험 연결

Firebase 프로젝트 `copilot-demo-c9a74`에서 패키지 `kr.haebom.elder`에 등록된 Android 앱의 `google-services.json`을 `app/`에 놓습니다. 파일이 있으면 Google Services 플러그인이 연결 설정을 생성합니다. 이 파일은 Git에서 제외되어 있습니다.

Firebase Authentication의 **익명** 로그인 제공업체가 켜진 환경에서, 디버그 앱 하단의 **Firebase 연결 확인**을 누릅니다. 익명 인증 UID를 어르신 ID로 사용하고 같은 UID의 `users/{uid}` 문서를 서버에서 읽어 연결을 확인합니다. 문서가 아직 없는 경우도 읽기 요청이 허용되면 연결 성공으로 표시합니다.
