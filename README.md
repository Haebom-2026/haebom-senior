# haebom-senior

해봄 고령자용 Android 앱입니다.

## 개발 환경

- JDK 21
- Android SDK Platform 35
- 최소 지원 버전 Android 8.0 (API 26)
- Gradle Wrapper 8.11.1

Android Studio에서 저장소 폴더를 열고 Gradle JDK를 21로 설정합니다. 터미널에서는 Android SDK를 `ANDROID_HOME`으로 지정한 뒤 디버그 APK를 빌드할 수 있습니다.

```sh
./gradlew :app:assembleDebug
```

Windows에서는 `gradlew.bat :app:assembleDebug`를 사용합니다. 빌드 결과는 `app/build/outputs/apk/debug/`에 생성됩니다.

## 화면 안내 연습

1. 앱에서 **접근성 설정 열기**를 누르고 **해봄 화면 안내** 서비스를 켭니다.
2. 앱으로 돌아와 **화면 안내 연습**을 엽니다. **다음** 버튼에 빨간 테두리가 표시됩니다.
3. 표시된 버튼을 누르면 테두리가 **연습 끝내기** 버튼으로 이동합니다. 연습을 끝내거나 다른 앱으로 이동하면 테두리가 사라집니다.

## 휴대전화 시험판

- 접근성 설정에서 **해봄 화면 안내**를 켜고 연습 또는 연락처 추가·유튜브 검색·정부24 등본 안내를 선택합니다.
- **말로 요청하기**는 기기의 한국어 음성 입력을 사용합니다. 음성 입력이 없는 기기에서도 안내 버튼을 눌러 실행할 수 있습니다. 자막을 음성으로 읽으려면 기기에 오프라인 한국어 TTS 음성이 설치되어 있어야 합니다.
- **도움 요청 문자**는 입력한 보호자 번호로 문자 앱을 엽니다. 문자 앱에서 내용을 확인한 후 전송을 눌러야 합니다.
- 정부24는 등본 발급 메뉴 안내까지만 제공하며, 본인인증 화면에서는 안내를 멈춥니다. 이 시험판에는 보호자 연결과 승인 전송이 포함되어 있지 않습니다.

화면 안내는 기기에서만 처리합니다. 입력란과 비밀번호는 읽지 않으며 앱은 화면을 전송하지 않습니다.
