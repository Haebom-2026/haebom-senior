## 해봄 고령자 앱 1차 기기 시험판

Android 8.0 이상에서 설치할 수 있습니다. 공기계 Chrome에서 아래 APK를 내려받아 설치한 뒤, 앱의 **접근성 설정 열기**에서 **해봄 화면 안내**를 켜 주세요.

- **화면 안내 연습**에서 빨간 테두리와 버튼 터치를 확인할 수 있습니다.
- **연락처 추가**, **유튜브 검색**, **정부24 등본**을 선택하면 해당 앱을 열고 화면에서 찾을 수 있는 항목을 안내합니다.
- 기기의 한국어 음성 입력과 오프라인 한국어 TTS 음성이 있으면 음성 기능을 사용할 수 있습니다.
- **도움 요청 문자**는 문자 앱을 열며, 전송은 이용자가 확인한 후 직접 누릅니다.
- 정부24 본인인증 단계에서는 안내를 중단합니다. 실제 보호자 알림과 승인은 서버 연동 뒤 검증합니다.
- **보호자 연동 연습 (Mock)**에서 6자리 코드 발급, 보호자 A·B 연결, 양쪽 보기의 해제 반영과 승인·거절 수신을 확인할 수 있습니다. 가상 계정과 데이터는 기기 안에서만 사용합니다.

접근성 서비스 스위치가 제한된 경우 휴대전화 설정의 **앱 → 해봄 어르신 → 더보기 → 제한된 설정 허용**이 표시되는지 확인해 주세요.

이 APK는 기기 테스트용 디버그 빌드입니다. Android 9 에뮬레이터에서 화면 안내를 검증했으며, 실제 정부24·유튜브와 제조사별 동작은 공기계 테스트 대상입니다.
